# CR7 — End of an Era

A cinematic, responsive fan-made Cristiano Ronaldo legacy tribute page.

## Features
- Animated CSS footballer performing a jump and landing celebration with a **SIUUU!** callout.
- Gold-on-black cinematic design, stadium atmosphere, floating dust and animated orbit rings.
- Scroll reveal effects, legacy statistics and timeline.
- Responsive layout for mobile and desktop.
- No build tools or dependencies required (Google Fonts are loaded online).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository named `CR7-Football-Legacy`.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site.

## Customize
Edit the text in `index.html`. Change colors and animation timing in `style.css`.

> This is a fan-made tribute concept. The 2003–2026 dates are used as the tribute's visual theme, not as a claim of an officially announced retirement.
